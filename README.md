# NanpinTrio

RSI・ゴールデンクロス・抵抗帯ブレイクの3シグナルで、トレンド方向にだけ入る MT5 用 EA です。
逆行したら1回だけナンピンし、損切りは浅く、利確は遠く置きます。含み益が乗ったら損切りを建値へ引き上げ、さらに伸びたら追従させます。
幅はすべて ATR 基準なので、ゴールド(XS セント口座)と BTC(Exness スタンダード)で同じファイルを使えます。

既定値は金向けです。

**MT5 の実データでは PF 1.10 でした(XS、XAUUSDp、2025年1月〜2026年11月、全ティック、攻め度3%で最大ドローダウン47%)。**
下のシミュレーション(金は PAXG で代用)の PF 1.93 は再現していません。金のシミュレーション結果は参考にしないでください。
実データで設定を見直すまで、本番での運用はおすすめしません。

## 入れ方

1. MT5 →「ファイル」→「データフォルダを開く」→ `MQL5/Experts/` に `NanpinTrio.mq5` を置く
2. MetaEditor で開いて F7(コンパイル)。エラーが出たら全文を送ってください
3. 取引したい銘柄のチャート(足は何でも可)に EA を載せる
   - ゴールド: 既定値のまま(`NanpinTrio_GOLD.set` と同じ)
   - BTC: パラメータ画面の「読み込み」で `NanpinTrio_BTC.set` を選ぶ。読み込めなければ下の表の値を手で入れる

ヘッジ口座専用です。同じ銘柄に2つ載せる時だけ `MagicNumber` を変えてください。

## 動き(既定値)

| 項目 | 内容 |
|---|---|
| シグナル① RSI | 確定足(M15)の RSI が 23〜30 に入ったら買い、70〜80 に入ったら売り |
| シグナル② MAクロス | 25MA が 75MA を上抜けで買い、下抜けで売り |
| シグナル③ ブレイク | 山(谷)が2回以上そろった価格帯を、終値で抜けたら順方向に入る |
| トレンドフィルター | H1 の EMA200 より上で、かつ EMA が6本前より上向きなら買いだけ。売りはその逆 |
| ナンピン | 初回建値から ATR×0.5 逆行で1回だけ、ロット1.5倍 |
| 損切り | 初回建値から ATR×1.0(ナンピン位置からさらに ATR×0.5)。損切り後は12時間休む |
| 利確 | 初回のみ: 建値+ATR×8 / ナンピン後: 平均建値+ATR×2 |
| 建値ストップ | 含み益が ATR×2 になったら損切りを平均建値へ移す |
| トレール | 含み益が ATR×6 になったら、現在値から ATR×4 離して損切りを追従させる |
| ロット | 損切りになった時の損失が残高の `BasketRiskPct`%(既定3%)になるよう自動計算 |

勝率は3割前後で、連敗が続きます(シミュレーションでは最大8連敗)。小さく負けて、たまに大きく勝つ形です。
引き上げた損切りで決済された時は、12時間の休止に入りません。

## MT5 での検証結果(実データ)

XS の実ティックで既定値(v1.20)を回した結果です。

| 項目 | MT5(実データ) | シミュレーション |
|---|---|---|
| PF | 1.10 | 1.93 |
| 勝率(バスケット単位) | 27% | 33% |
| 最大ドローダウン(攻め度3%) | 47% | 26% |
| 2025年 / 2026年の PF | 1.31 / 1.08 | 1.96 / 1.90 |

- エントリーの時刻が一致したのは409回中95回だけ。15分足のシグナルは細かい値動きに敏感で、PAXG では出るタイミングがほとんど違っていた
- 時刻が一致した取引は勝ち負けが92.6%同じ。損切り・利確・建値ストップの処理は EA とシミュレーターで合っている
- ナンピンが入った取引(301回)は勝率19%・PF 0.68、ナンピンなしで終わった取引(116回)は PF 8.76
- シグナル別の PF: デッドクロス 1.58 / ゴールデンクロス 1.30 / ブレイク 1.25 / RSI 0.95

## シミュレーションの結果(金は実際より甘い)

Binance の1分足(金は金連動トークン PAXG で代用、BTC は BTCUSDT)で 2025年1月〜2026年10月を回しました。

| 設定 | PF | 2025年 | 2026年 | 勝率 |
|---|---|---|---|---|
| 金: 6段ナンピン(v1.00) | 0.44 | 0.40 | 0.51 | 98% |
| 金: 順張り+ナンピン1回(v1.10) | 1.73 | 1.93 | 1.55 | 32% |
| 金: 上に傾き・建値ストップ・トレールを追加(現在の既定値) | 1.93 | 1.96 | 1.90 | 33% |
| BTC: 6段ナンピン | 0.69 | 0.85 | 0.58 | 99% |
| BTC: 順張り・ナンピンなし(v1.10) | 1.46 | 1.44 | 1.48 | 15% |
| BTC: 上に建値ストップを追加(`NanpinTrio_BTC.set`) | 1.54 | 1.50 | 1.60 | 10% |

金の既定値での月利と最大ドローダウン(複利):

| `BasketRiskPct` | 月利(中央値) | 最大ドローダウン |
|---|---|---|
| 3% | 約26% | 26% |
| 5% | 約43% | 40% |
| 8% | 約66% | 58% |

v1.20 で追加ロジックを12種類試しました(金、v1.10 の PF 1.73 に1つずつ追加):

| 追加したロジック | PF | 判定 |
|---|---|---|
| ADX が25以上の時だけ | 1.53 | 不採用 |
| H4 の EMA50 も同じ向き | 1.71 | 不採用 |
| 日足の EMA20 も同じ向き | 1.62 | 不採用 |
| ボラティリティが平均以上 | 1.48 | 不採用 |
| ロンドン〜NY 時間だけ | 1.37 | 不採用 |
| 2種類以上のシグナルが重なった時だけ | 0.87 | 不採用 |
| シグナル足が陽線(陰線)の時だけ | 1.53 | 不採用 |
| EMA から離れすぎていない時だけ | 1.57 | 不採用 |
| EMA が傾いている時だけ | 1.79 | 採用 |
| 建値ストップ | 1.83 | 採用 |
| トレール | 1.80 | 採用 |
| 採用した3つを全部 | 1.93 | 既定値 |

- エントリーを厳しく絞るフィルターは、どれも PF を下げました。取引が減るだけで質は上がっていません
- ナンピンの段数を増やすほど PF は下がりました(700通りの中央値で 1段 0.94 → 8段 0.57)。`MaxLevels` は2までにしてください
- BTC の設定は、スプレッドを2倍に見積もると PF が 1.2 まで落ちます。少額で試す前提です
- 2025〜2026年は金のトレンドが強かった時期です。設定も追加ロジックもこの期間を見て選んだので、実運用の PF はこれより下がると考えてください。PF の 0.1〜0.2 程度の差は偶然でも出ます
- XS・Exness の実際のスプレッドや約定は反映していません

シミュレーターは `sim/ntsim.py` にあります(EA と同じルールを1分足で再現)。

## MT5 でのバックテスト

- モデル: **全ティック(リアルティックに基づく)**
- 期間: 1年以上
- 初期証拠金: 実際に入れる額(セント口座はセント建ての額)
- 見るところ: PF、最大ドローダウン、最大連敗

レポート(HTML)を送ってもらえれば、シミュレーションとの差を確認して値を詰めます。
