# NanpinTrio

MAクロス(ゴールデンクロス / デッドクロス)でトレンド方向にだけ入る MT5 用 EA です。
損切りは浅く、利確は遠く置き、含み益が乗ったら損切りを建値へ引き上げて追従させます。
RSI・抵抗帯ブレイク・ナンピンも入っていますが、金の実データでは逆効果だったので既定ではオフです。

既定値(v1.30)は金向けで、実際の金のティックで検証した設定です。MT5 のテスターでの確認はまだです。

## 入れ方

1. MT5 →「ファイル」→「データフォルダを開く」→ `MQL5/Experts/` に `NanpinTrio.mq5` を置く
2. ナビゲーターの「エキスパートアドバイザ」を右クリック →「更新」(自動でコンパイルされる)
3. 取引したい銘柄のチャート(足は何でも可)に EA を載せる
   - ゴールド: 既定値のまま(`NanpinTrio_GOLD.set` と同じ)
   - BTC: パラメータ画面の「読み込み」で `NanpinTrio_BTC.set` を選ぶ(MT5 では未確認の設定)

ヘッジ口座専用です。同じ銘柄に2つ載せる時だけ `MagicNumber` を変えてください。

## 動き(既定値)

| 項目 | 内容 |
|---|---|
| エントリー | M15 の 25MA が 75MA を上抜けで買い、下抜けで売り |
| トレンドフィルター | H1 の EMA200 より上で、かつ EMA が6本前より上向きなら買いだけ。売りはその逆 |
| 損切り | 建値から ATR×1.5(H1 の ATR)。損切り後は4時間休む |
| 利確 | 建値+ATR×8 |
| 建値ストップ | 含み益が ATR×2 になったら損切りを建値へ移す |
| トレール | 含み益が ATR×4 になったら、現在値から ATR×3 離して損切りを追従させる |
| ロット | 損切りになった時の損失が残高の `BasketRiskPct`%(既定3%)になるよう自動計算 |

勝率は約37%で、小さく負けて、たまに大きく勝つ形です。検証では8連敗があり、22か月のうち8か月がマイナスでした。

オフにしてある機能: `UseRSI`(RSI 23〜30 で買い / 70〜80 で売り)、`UseBreakout`(抵抗帯・支持帯ブレイク)、`MaxLevels`(2以上でナンピン)。

## 検証の結果(金、実データ)

Exness が公開している XAUUSDm のティック履歴(実際のスプレッド込み)で、2025年1月〜2026年10月を回しました。

まず、同じ設定(v1.20)で XS の MT5 と一致するかを確かめています。

| | XS の MT5 | シミュレーション |
|---|---|---|
| 取引のまとまりの数 | 409回 | 410回 |
| PF | 1.19 | 1.21 |
| ナンピンが入った取引の PF | 0.68(301回) | 0.69(301回) |
| 同じ時刻・同じ方向で入った割合 | 87%(そのうち勝ち負けの一致は97.7%) | |

そのうえでの設定ごとの結果です。

| 設定 | PF | 2025年 | 2026年 | 勝率 | プラスの四半期 |
|---|---|---|---|---|---|
| ナンピン1回+3シグナル(v1.20) | 1.21 | 1.39 | 1.02 | 29% | 5 / 8 |
| ナンピンなし+3シグナル | 1.38 | 1.61 | 1.16 | 22% | 6 / 8 |
| MAクロスのみ・ナンピンなし(v1.30 の既定値) | 2.01 | 2.01 | 2.02 | 37% | 8 / 8 |

既定値での月利と最大ドローダウン(複利):

| `BasketRiskPct` | 月利(平均) | 月利(中央値) | 最大ドローダウン |
|---|---|---|---|
| 2% | 約10% | 約6% | 23% |
| 3% | 約15% | 約9% | 33% |
| 5% | 約23% | 約12% | 49% |

既定値から1つだけ変えた時の PF:

| 変更点 | PF |
|---|---|
| ナンピンを1回入れる | 1.56 |
| RSI シグナルも使う | 1.64 |
| ブレイクシグナルも使う | 1.54 |
| 3シグナルすべて使う | 1.43 |
| トレンドフィルターと傾きを外す | 1.34 |
| 建値ストップを外す | 1.85 |
| トレールを外す | 1.85 |
| 損切りを ATR×1.0 に | 2.22 |
| 損切りを ATR×2.0 に | 2.04 |
| 利確を ATR×4 に | 1.69 |
| MA を 30/90 に | 1.95 |
| MA を 20/50 に | 1.40 |
| スプレッドを0.3ドル広く | 1.97 |
| スプレッドを0.6ドル広く | 1.85 |

損切り幅・トレール・休止時間・MA の期間を変えた36通りでは、PF はすべて 1.80〜2.25 でした。

### 注意

- 設定は2025年と2026年の両方を見て選んでいます。別の期間で確かめたわけではないので、実運用の PF はこれより下がると考えてください
- 以前の版では金を金連動トークン(PAXG)で代用していて、MT5 と大きくずれました(シミュレーション PF 1.93 に対し MT5 は 1.10)。15分足のシグナルは細かい値動きに敏感で、代用データは使えません
- BTC の設定は Binance の価格で計算したままで、MT5 との照合をしていません。金と同じようにずれる可能性があります
- 月利50%には届きません

## シミュレーター

`sim/` に入っています。

- `tick2m1.py`: Exness のティック履歴(zip)を1分足とスプレッドに変換
- `exload.py`: 変換したデータの読み込みと、サーバー時間(ニューヨーク時間+7時間)への変換
- `ntsim.py`: EA と同じルールを1分足で再現
