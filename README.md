# NanpinTrio

RSI・ゴールデンクロス・抵抗帯ブレイクの3シグナルで入り、逆行したらナンピン、平均建値+αでまとめて利確する MT5 用 EA です。
幅はすべて ATR 基準なので、ゴールド(XS セント口座)と BTC(Exness スタンダード)で同じファイルを使えます。

**まだ実データでのバックテストをしていません。** 既定値は計算上の目安です。実運用の前に必ずテスターで確認してください。

## 入れ方

1. MT5 →「ファイル」→「データフォルダを開く」→ `MQL5/Experts/` に `NanpinTrio.mq5` を置く
2. MetaEditor で開いて F7(コンパイル)。エラーが出たら全文を送ってください
3. 取引したい銘柄のチャート(足は何でも可)に EA を載せる
   - ゴールド: XS セント口座のゴールド銘柄
   - BTC: Exness スタンダードの BTCUSD(土日も動く銘柄は時間フィルターが自動で無効)

ヘッジ口座専用です。買いと売り、ゴールドと BTC は `MagicNumber` で区別します(同じ口座で2銘柄動かすなら番号を変える必要はありませんが、同じ銘柄に2つ載せる時は変えてください)。

## 動き

| 項目 | 内容 |
|---|---|
| シグナル① RSI | 確定足の RSI が 23〜30 に入ったら買い、70〜80 に入ったら売り |
| シグナル② MAクロス | 短期MA(25)が長期MA(75)を上抜けで買い、下抜けで売り |
| シグナル③ ブレイク | 山(谷)が2回以上そろった価格帯を、終値で抜けたら順方向に入る |
| トレンドフィルター | H1 の EMA200 より上なら買いだけ、下なら売りだけ(オフにもできる) |
| ナンピン | 初回建値から ATR×1.0、次は×1.3 倍ずつ広げて最大6段、ロットは1.5倍ずつ |
| 利確 | 初回のみ: 建値+ATR×0.6 / ナンピン後: 平均建値+ATR×0.35 で全決済 |
| 損切り | 最終段から ATR×2.0 逆行で全決済し、12時間は新規を休む |
| ロット | 全段入って損切りになった時の損失が、残高の `BasketRiskPct`% になるよう自動計算 |

パネルに「全段損切り時の想定損失 %」が出ます。残高が小さくて最小ロットでも設定%を超える場合は、その旨が表示されます。

## 攻め度(`BasketRiskPct`)

1回の損切りで失う残高の割合です。既定は 30。
利確1回の利益はこの値に比例するので、月利を上げたければここを上げることになりますが、損切り1回の損失も同じだけ大きくなります。
30 / 60 / 100 の3通りでバックテストして比べるのがおすすめです。

## バックテストのやり方

- モデル: **全ティック(リアルティックに基づく)**。「始値のみ」ではナンピンと利確が正しく再現されません
- 期間: 1年以上。上昇・下落・レンジの時期がすべて入るように
- 初期証拠金: 実際に入れる額と同じにする(セント口座はセント建ての額)
- 見るところ: PF、最大ドローダウン、損切り(コメントなしで6ポジション同時決済)の回数

レポート(HTML)を送ってもらえれば、銘柄ごとに値を詰めます。
