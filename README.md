# NanpinFX(FX・ナンピン最大10回)

FX 用の MT5 EA です。RSI(1時間足)が25未満で買い、75超で売りを始め、逆行したらナンピンを最大10回入れて、平均建値から利確します。

初回ロットは「ナンピン10回を全部入れ、さらに1段分逆行した**耐えるライン**で全決済した時の損失 = 残高の `RiskPct`%」になるよう、残高から自動で決まります。
つまり、どのロットでも必ずナンピン10回(+1段)までは耐えます。

| | 既定値 |
|---|---|
| エントリー | 1時間足 RSI(14) が25未満で買い・75超で売り(買いと売りは別々に持てる) |
| ナンピン幅 | 1回目は日足ATR(14)×0.6、以後1.2倍ずつ広げる(EURUSD なら約44 → 53 → 63 pips…) |
| ロット | 1.7倍ずつ(11本目は初回の約200倍) |
| 利確 | 平均建値から日足ATR×0.6 |
| 耐えるライン | 10回目のナンピンから、さらに1段分先(初回から日足ATR×19.3。EURUSD で約1,400pips) |
| 攻め度 `RiskPct` | 30%(耐えるラインで全決済した時に残高の30%を失う) |

**MT5 のテスターではまだ確認していません。** 下の数字はシミュレーションの結果です。

## 先に結論: 月利50%は出ません

「ナンピン10回に耐える」と「月利50%」は両立しませんでした。

- 15通貨ペア × 1,512通りの設定 × 11年分(2016年1月〜2026年10月、実ティック)を回して、10回耐えるロットのまま月利50%に届いた組み合わせは **0** でした。月利5%に届いたものも0。一番良かったのは、1つの通貨ペアだけで、攻め度を後から一番良い値にした場合の月利4.3%です
- 10回耐えるロットは小さく、既定設定(攻め度30%)だと、初回だけで利確した時の利益は残高の約0.005%です。1ペアで月に2〜3回しか入らないので、月利は0.1%前後になります
- 既定設定で月利50%に届くロットは、10回耐えるロットの約200倍です(攻め度100%でも月0.27%のため)。そのロットだと、口座はナンピン3〜4回目で尽きます。ロットを100倍・300倍にして12ペア×開始日20通りで試すと、99〜100%の口座が飛び、飛ぶまでの中央値は4か月・2か月でした
- よくある形(幅は日足ATRの0.25倍で EURUSD なら約20pips・ロット1.5倍・利確はその半分の約10pips、常時エントリー)も試しました。耐えるラインでの損失を30%に抑えたロットでも89%の口座が飛び(中央値15か月)、100%にすると全部が飛びました(中央値1か月)。そのうち40%は、飛ぶ前に月利50%以上の月がありました。**「月利50%」のバックテストは、だいたいこの状態です**

## 既定設定の成績

15通貨ペア、2016年1月〜2026年10月。新規は23時〜1時(サーバー時間)と金曜20時以降は入らず、スプレッド3pips超でも入らない(EA の既定と同じ)。

| `RiskPct` | 月利(15ペアの中央値) | ペアごとの幅 | 最大ドローダウン(中央値) | 最大ドローダウン(最悪のペア) | 耐えるラインに届いた回数 |
|---|---|---|---|---|---|
| 10% | 0.03% | 0.02〜0.04% | 2% | 9% | 0 |
| **30%(既定)** | **0.08%** | 0.06〜0.11% | 6% | 26% | 0 |
| 60% | 0.16% | 0.12〜0.21% | 12% | 53% | 0 |
| 100% | 0.27% | 0.20〜0.36% | 21% | 88% | 0 |

- 15ペアすべてが、11年のどの年もプラスでした(攻め度30%で、年ごとの月利は0.01〜0.28%)
- ナンピン10回目まで全部入った(11本持った)ことは EURUSD・GBPUSD・EURGBP・USDCAD・AUDJPY でありました。それでも耐えるラインには届きませんでした
- 一番長く抱えたバスケットは500日(AUDUSD)、次が411日(EURJPY)。含み損を1年以上抱えることもある EA です
- 対象: EURUSD, USDJPY, GBPUSD, AUDUSD, EURGBP, AUDNZD, AUDCAD, EURJPY, NZDCAD, USDCAD, USDCHF, NZDUSD, EURCHF, GBPJPY, AUDJPY

### 注意

- 「11年で一度も届かなかった」は運も含みます。GBPJPY は、入るタイミングが少し違えば届いていました(時間・スプレッドの絞り込みを外し、開始日を20通り変えると、7通りで2019年8月5日に耐えるラインに到達)。数年〜十数年に一度、残高の `RiskPct`% を失う日が来ると考えてください
- データより前の事件、たとえば2015年1月のスイスフランショック(EURCHF が数分で3,000pips 以上動いた)は、この設定の耐えるライン(EURCHF で約930pips)を越えます
- 既定設定の選び方: 1,512通りの総当たり(絞り込みなし)で、13ペア以上が前半(〜2021年6月)も後半もプラスだった91通りを、EA と同じ絞り込み込みで回し直し、「15ペアすべてでプラス・耐えるライン0回」の中で月利が一番高かったもの。総当たりの段階では、GBPJPY が上の2019年8月に1回届いています。選んだ期間の成績なので、実運用ではこれより下がる前提で見てください
- スワップの上乗せを年1.5%から3%にすると、月利は1〜3割下がります(5ペアで確認。マイナスにはなりませんでした)

## 必要な残高

耐えるラインがとても遠く、ロットも1.7倍ずつ増えるので、最小ロット(0.01)でも大きな残高が要ります。
`RiskPct` 30% で 0.01 ロットから動かすのに必要な残高(2016〜2026年の日足ATRの中央値で計算):

| 通貨ペア | 日足ATR | 必要な残高 |
|---|---|---|
| EURUSD | 73pips | 約8.6万ドル |
| GBPUSD | 98pips | 約11.5万ドル |
| AUDUSD | 62pips | 約7.3万ドル |
| USDJPY | 91pips | 約1,070万円 |
| EURJPY | 103pips | 約1,210万円 |
| GBPJPY | 139pips | 約1,640万円 |
| AUDJPY | 82pips | 約970万円 |

残高が足りない時、EA は新規を見送ります(`UseMinLotIfSmall=false`)。パネルに「最小ロットで動かすのに必要な残高」が出ます。
`UseMinLotIfSmall=true` にすると最小ロットで入りますが、耐えるラインでの損失は `RiskPct` を超え、残高によっては10回耐えられなくなります(パネルとエキスパートタブのログに実際の%が出ます)。

ロット倍率を下げる・幅を狭めるなどで必要な残高を5分の1以下にした設定も16通り試しましたが、どれも15ペア中1〜8ペアで負け、耐えるラインにも届き(合計1〜10回)、最大ドローダウンは最悪のペアで33〜74%になりました。月利の中央値は-0.08〜0.12%で、既定設定とほとんど変わりません。

## 攻め度を上げた場合(ロットを何倍にすると、どうなるか)

既定設定のロットを、10回耐えるロットの何倍にするか。12ペア × 開始日20通り(2016年3月〜2025年9月、半年ごと)、時間・スプレッドの絞り込みなし。「飛んだ」= 残高が最初の10%未満。1倍で飛んだ3%は、すべて GBPJPY の2019年8月です。

| ロット | 口座が尽きる位置 | 飛んだ割合 | 飛んだ口座の、飛ぶまで | 最初の12か月の月利(中央値) | 飛ぶ前に月利50%の月があった |
|---|---|---|---|---|---|
| 1倍(`RiskPct` 100%) | 耐えるライン | 3% | 24か月 | 0.3% | 0% |
| 3倍 | ナンピン9回目の後 | 17% | 29か月 | 0.8% | 0% |
| 10倍 | 7回目の後 | 72% | 23か月 | 2.3% | 0% |
| 30倍 | 6回目の後 | 96% | 11か月 | -25% | 0% |
| 100倍 | 4回目の後 | 99% | 4か月 | -42% | 16% |
| 300倍 | 3回目の後 | 100% | 2か月 | -82% | 38% |

EA の `RiskPct` は100%までしか入りません(100%を超えると、10回耐えられないため)。

## 入れ方

1. MT5 →「ファイル」→「データフォルダを開く」→ `MQL5/Experts/` に `NanpinFX.mq5` を置く
2. ナビゲーターの「エキスパートアドバイザ」を右クリック →「更新」(自動でコンパイルされる)
3. 通貨ペアのチャートに載せる(足は何でも可)
4. パネルで「次の初回ロット」「耐えるラインでの損失」「最小ロットで動かすのに必要な残高」を確認する

- ヘッジ口座専用です
- 複数の通貨ペアで同時に動かす時、攻め度はペアごとに残高全体にかかります。5ペアで30%ずつなら、全部が同時に耐えるラインに届くと150%です
- 時刻はサーバー時間で判定します。検証はニューヨーク時間+7時間(XM・XS などと同じ)で行いました

## パラメータ

| パラメータ | 既定値 | 意味 |
|---|---|---|
| `RiskPct` | 30 | 耐えるラインで全決済した時の損失(残高の%)。ロットはここから自動計算 |
| `FixedBaseLot` | 0 | 初回ロットを固定する時に入れる(0=自動) |
| `UseMinLotIfSmall` | false | 自動ロットが最小ロット未満でも最小ロットで入るか |
| `MaxNanpin` | 10 | ナンピン回数の上限(初回は含まない。10なら最大11本) |
| `StepBase` | 日足ATR | ナンピン幅を日足ATRの倍率で決めるか、pips で固定するか |
| `StepATR` / `StepPips` | 0.6 / 20 | 1回目のナンピン幅 |
| `StepGrow` | 1.2 | 幅の拡大率(回ごと) |
| `LotMult` | 1.7 | ロット倍率(回ごと) |
| `TPRatio` | 1.0 | 利確幅 = 1回目のナンピン幅 × この値(平均建値から) |
| `SurviveSteps` | 1.0 | 10回目のナンピンの先に取る余裕(次のナンピン幅の何回分か) |
| `CutAtSurvive` | true | 耐えるラインで全決済する。false にすると持ち続ける(口座ごと飛ぶ危険) |
| `EntryMode` | RSI | RSI で入るか、常時入るか |
| `RSI_BuyBelow` / `RSI_SellAbove` | 25 / 75 | RSI の基準 |
| `TrendMAPeriod` | 0 | 日足EMAの向きにだけ入る(0=使わない。EMA200 で試したが、既定設定より良い組み合わせはなかった) |
| `BothSides` | true | 買いと売りを同時に持てる |
| `MaxSpreadPips` | 3 | これより広い時は新規もナンピンもしない |
| `MaxDDStopPct` | 0 | 残高ピークからこの%減ったら全決済して停止(0=使わない) |

そのほか: 新規を止める時間帯(既定は23時〜1時と金曜20時以降、サーバー時間)、ナンピン同士の最低間隔、証券会社側にも利確・損切りを置くか、1注文の最大ロット、マジックナンバー。

## 検証の方法

- データ: Exness が公開しているティック履歴(スタンダード口座、実際のスプレッド込み)。2016年1月〜2026年10月、15ペア
- `sim/fx_fetch.py` で1分足(Bid の四本値・平均スプレッド・Ask の高値安値)に変換し、`sim/gridsim.py` で EA と同じ規則を再現。足の中は、陽線なら始値→安値→高値→終値、陰線なら始値→高値→安値→終値と動いたとみなす
- スワップ: 各国の政策金利のおおよその年平均の差から、証券会社の上乗せ年1.5%を引いた値。水曜は3日分
- 口座通貨はその通貨ペアの決済通貨、レバレッジ1000倍、証拠金維持率20%でロスカット。ロットは端数ありで計算(0.01ロット単位の丸めなし)
- 再現: `python3 sim/fx_research.py screen|full|ruin データのフォルダ 出力.pkl EURUSDm USDJPYm ...`

# NanpinTrio

MAクロス(ゴールデンクロス / デッドクロス)でトレンド方向にだけ入る、金(ゴールド)向けの MT5 用 EA です。
損切りを置き、利確は遠く、含み益が乗ったら損切りを建値へ引き上げます。

2つの設定を、別々のチャートで同時に動かす想定です。

| | 遅い設定 | 速い設定 |
|---|---|---|
| 設定ファイル | `NanpinTrio_GOLD_slow.set` | `NanpinTrio_GOLD_fast.set` |
| いつ動くか | 常時 | 日足ATRが価格の1.6%以上の時だけ |
| エントリー | M15 の 75MA と 225MA のクロス | M15 の 25MA と 75MA のクロス |
| 損切り | ATR×3 | ATR×1.5 |
| 建値ストップ | 含み益 ATR×3 | 含み益 ATR×2 |
| トレール | なし | 含み益 ATR×4 から ATR×3 幅 |
| マジックナンバー | 20261113 | 20261114 |

共通: H1 の EMA200 の方向で、EMA が6本前より傾いていて、さらに日足 EMA60 とも同じ向きの時だけ入る。利確は ATR×8。損切り後は4時間休む。
ロットは、損切りになった時の損失が残高の `BasketRiskPct`%(既定3%)になるよう自動計算。

EA の既定値は「遅い設定」と同じです。
RSI・抵抗帯ブレイクも機能として残っていますが、6年分の検証では成績を下げたので、既定ではオフです。
ナンピンは既定ではオフ(`MaxLevels=1`)で、ナンピンありの設定ファイルも用意してあります(下記)。

**MT5 のテスターではまだ確認していません。** 下の数字はシミュレーションの結果です。

## 入れ方

1. MT5 →「ファイル」→「データフォルダを開く」→ `MQL5/Experts/` に `NanpinTrio.mq5` を置く
2. ナビゲーターの「エキスパートアドバイザ」を右クリック →「更新」(自動でコンパイルされる)
3. 金のチャートを2つ開く(足は何でも可)
4. 1つ目に EA を載せ、パラメータ画面の「読み込み」で `NanpinTrio_GOLD_slow.set` を選ぶ
5. 2つ目に EA を載せ、同じく `NanpinTrio_GOLD_fast.set` を選ぶ

設定ファイルが読み込めない時は、上の表の値と `MagicNumber`、`MinDailyATRpct`(速い設定は1.6、遅い設定は0)を手で入れてください。
マジックナンバーは必ず別の値にします。同じだと2つの EA がお互いのポジションを自分のものとして扱ってしまいます。

ヘッジ口座専用です。

## ナンピンを使う場合

| パラメータ | 意味 |
|---|---|
| `MaxLevels` | エントリーする本数の上限(1=ナンピンなし、2=ナンピン1回) |
| `StepPrice` | ナンピン幅を価格で指定(金なら 3.5 = 3.5ドル逆行で追加)。0 なら `StepATR`(ATR の倍率)を使う |
| `StepGrow` | 回ごとの幅の拡大率(1.3 なら 3.5 → 4.55 → 5.9 ドル) |
| `LotMult` | 回ごとのロット倍率(1.0 なら同じロット) |
| `StopATR` | 最後のナンピンから損切りまでの幅(ATR の倍率) |
| `TPNanpin_ATR` | ナンピン後の利確幅(平均建値から、ATR の倍率) |

ロットは、全部入って損切りになった時の損失が `BasketRiskPct`% になるよう自動で小さくなります。

ナンピン1回の設定ファイル: `NanpinTrio_GOLD_slow_nanpin.set` / `NanpinTrio_GOLD_fast_nanpin.set`
(3.5ドル逆行で同じロットを1本追加。損切りは2本目から ATR×2、速い設定は ATR×1)。ナンピンなしの設定ファイルと入れ替えて使います。

6年分のシミュレーション(遅い+速いの併用、攻め度3%ずつ):

| 設定 | PF | 月利(平均) | 最大DD | 最悪の年の PF |
|---|---|---|---|---|
| ナンピンなし | 2.18 | 7.1% | 34% | 1.07 |
| ナンピン1回(幅3.5ドル、最大2本) | 2.39 | 8.5% | 36% | 1.10 |
| ナンピン2回(幅3.5→4.55ドル、最大3本) | 2.06 | 5.2% | 33% | 1.30 |
| ナンピン4回(最大5本、ロット1.5倍) | 1.56 | 1.4% | 26% | 0.68 |
| 幅35ドルでナンピン1回 | 1.75 | 1.8% | 26% | 1.29 |

- 1回だけ・小さい幅(2〜5ドル)なら、ナンピンなしとほぼ同じか少し良い結果でした。幅を2〜5ドルで変えても PF は 2.26〜2.39 に収まります
- 本数を増やすほど利益が減ります。ロットを倍にしていくとさらに悪化します
- ナンピン後に利確を近くする(平均建値から ATR×2)と PF は 1.5 前後まで落ちます。利確は遠いままにしてください
- 上の数字はシミュレーションどおりの場合です。実運用では下の「実運用で期待できる数字」と同じ目減りを見込んでください

日足フィルターを入れると、取引数は約26%減り、併用の PF は 1.76 から 2.18 に上がりました。

### 実運用で期待できる数字

上の数字は、6年分を見て選んだ設定の成績なので、実運用ではこれより下がります。
どれくらい下がるかを、9,527通りの設定で「過去のデータで上位を選び、選びに使っていない年で試す」検証をして測りました。

| 選び方 | 選んだ時の PF | 別の年での PF |
|---|---|---|
| 5年で上位20を選び、残り1年で試す(全6通り) | 2.45 | 1.73 |
| 5年で上位50を選び、残り1年で試す | 2.25 | 1.53 |
| 過去だけで上位20を選び、翌年に試す(2023〜2026年) | 2.40 | 1.74 |
| 過去だけで上位50を選び、翌年に試す | 2.16 | 1.73 |

利益から損失を引いた分(優位性)は、おおむね半分になります。現在の設定(シミュレーション 2.18)は、実運用では **PF 1.5〜1.8 程度** と考えてください。
その場合の月利(併用、複利):

| `BasketRiskPct` | 6年平均 | 最大ドローダウン | 2026年のような相場 | それ以外の年 |
|---|---|---|---|---|
| 3% ずつ | 月3.4% | 35% | 月13.5% | 月1.9% |
| 5% ずつ | 月5.3% | 52% | 月21.8% | 月2.8% |
| 8% ずつ | 月7.4% | 71% | 月33.1% | 月3.6% |

月利50%は、どの攻め度でも届きません。シミュレーションどおりに勝てたとしても、6年平均の上限は月27%(攻め度20%、最大ドローダウン95%)で、それ以上攻めると逆に減ります。目減り込みなら上限は月9%です。

### わかったこと

- v1.30 の PF 2.01 は2025〜2026年だけの成績で、2021〜2024年は 0.68〜1.08 でした
- 2023〜2026年の4年すべてで勝てた299の設定を2021〜2022年に当てると、PF の中央値は 0.90 で、無作為に選んだ設定と同じでした。ある期間で良かった設定は、別の期間では当てになりません
- 6年とも崩れなかったのは、遅い MA クロス(75〜100 / 150〜225)と広い損切りの組み合わせだけでした
- 速い MA クロスは、日足ATRが価格の1.6%以上の時だけ通用しました(境目は 1.5〜1.8% のどれでも近い結果。1.4% まで下げると最大ドローダウンが63%に悪化)
- RSI・抵抗帯ブレイク・ナンピンは、どの期間でも成績を下げました
- 金だけで攻め度を上げても、6年平均の月利は10%前後で頭打ちです

### 注意

- どちらの設定も、6年分のデータを見て選んでいます。似た設定でも年によって負けるものがあり(遅い設定で MA 90/180 にすると2024年は PF 0.53)、実運用の PF は 1.3〜1.7 程度の幅で考えてください
- 値動きが大きい時期は6年のうち2026年に集中しているので、速い設定の裏付けは遅い設定より弱いです
- 併用でも70か月のうち24か月がマイナスで、最大連敗は10回でした
- 日足フィルターの改善は、前半(2021〜2023年)より後半(2024〜2026年)のほうが大きく出ています
- 以前の版では金を金連動トークン(PAXG)で代用していて、MT5 と大きくずれました。15分足のシグナルは細かい値動きに敏感で、代用データは使えません
- BTC は同じ方法で検証していないため、設定ファイルを外しました

## MT5 でのバックテスト

- モデル: **全ティック(リアルティックに基づく)**
- 期間: できるだけ長く(2021年〜)
- 初期証拠金: 実際に入れる額
- 遅い設定と速い設定を、それぞれの設定ファイルを読み込んで別々に回す
